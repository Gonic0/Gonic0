#### Open source

I'm helping bring [AnyPS5](https://github.com/boykopovar/AnyPS5) to macOS on Apple Silicon, testing builds under Rosetta 2 and investigating graphics and portability issues. I focus on reproducible reports with the tested revision, hardware, measurements and remaining limits.

- **Code:** [libSceNet fixes for macOS — PR #9231](https://github.com/boykopovar/AnyPS5/pull/9231), covering FreeBSD `inet_pton` rules and socket errors.
- **Investigation:** [portability-subset findings and a reproduction probe](https://github.com/boykopovar/AnyPS5/pull/10540#issuecomment-6388121653). [The follow-up by maximilianfv](https://github.com/boykopovar/AnyPS5/pull/10540#issuecomment-6396300348) links those findings to PR #10920.
- **Independent testing:** [before/after validation of #10920 on an M5 Pro](https://github.com/boykopovar/AnyPS5/pull/10920#issuecomment-6398446765), including unchanged failures and the limits of the test setup.
